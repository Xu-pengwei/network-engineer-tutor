# Packetlyra · Network Engineer Tutor

A Chinese-language Skill for computer networking study and guided labs. [简体中文](README.md)

## Status

V1.1.2 correction candidate. Independent acceptance testing is incomplete. This is a separate release-preparation copy, not evidence of publication or installation.

## Contents

Guidance covers networking theory, exam practice, VMware and server labs, Wireshark analysis, IP planning, troubleshooting, and Python networking projects. The Skill contains its main instructions, 11 reference files, four blank record templates, and a changelog. Python project lists describe a learning roadmap; implementations are not included.

- `skills/network-engineer-tutor/SKILL.md`: main instructions
- `skills/network-engineer-tutor/references/`: subject references

- `skills/network-engineer-tutor/CHANGELOG.md`: original version history

## Usage and compatibility

Read the main instructions and confirm client support for Skill discovery, reference loading, and tool permissions. Installation paths, commands, and supported clients remain unverified; no installation command is provided yet.

Example requests: explain DNS and ask a review question; analyze supplied diagnostic output using read-only checks first; draft a lab report and mark missing evidence as unverified.

## Authorization and privacy

Drafts do not imply execution. File changes, configuration changes, dependency installation, active network probes, local commits, and remote pushes require authorization for their respective scope. Use only owned or explicitly authorized test environments.

Save real learning records only to approved locations. Do not publish credentials, private records, internal topology, or unsanitized packet captures.

## Limitations

Automatic script execution, persistent learning-data storage, automatic Git commits or pushes, email notifications, and scheduled reminders are not implemented. Fourteen offline static checks passed. User-supplied chat responses were reviewed for content: status naming and authorization-plan inconsistencies were observed; the uploaded-template draft broadly matched the template. These observations do not establish local Skill loading or tool-level behavior. Local loading, full runtime behavior, and cross-client compatibility remain unverified. Listing a Skill does not prove compatibility. Review dates and commit messages are suggestions or drafts only.

The supplied files are Markdown instructions and templates, with no executable tools or dependency installer. Labs may require separately prepared operating systems, virtualization software, Python, or Wireshark. Third-party plugins are optional.
