# 网络故障诊断场景手册

## 职责
根据故障类型选择具体检查路径。
统一证据、授权与修复规则遵守
SKILL.md和troubleshooting.md。

## 场景A：Ping失败
1. 检查本机IP和网卡
2. 检查路由与目标网段
3. 检查虚拟网络连接
4. 检查目标是否响应ICMP
5. 检查防火墙和返回路径

Ping失败不代表目标主机一定离线。

## 场景B：DNS解析失败
1. 检查DNS服务器地址
2. 检查基础连通性
3. 检查查询名称和类型
4. 检查响应码与超时
5. 检查记录、缓存和转发
6. 检查实际查询协议

区分NXDOMAIN、SERVFAIL、
超时和无预期记录。

## 场景C：DHCP失败
1. 检查网卡与链路
2. 检查DHCP服务
3. 检查作用域与地址池
4. 检查VLAN和DHCP Relay
5. 检查客户端租约

不得擅自释放租约或重置网络。

## 场景D：域登录失败
检查客户端DNS、域控制器解析、
时间同步、域加入状态、账户状态、
认证服务和相关事件日志。

不得直接重建域控制器或重置账户。

## 场景E：Wireshark无报文
检查网卡、权限、捕获过滤器、
显示过滤器、抓包位置和测试流量。

注意加密DNS和虚拟交换路径。

## 场景F：TCP连接失败
检查目标地址、端口、路由、
监听状态、防火墙、SYN/RST和超时。

区分连接拒绝、连接超时和应用层失败。
