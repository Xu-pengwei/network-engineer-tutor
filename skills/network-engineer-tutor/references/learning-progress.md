# 学习进度与错题管理

## 职责
管理学习计划、学习状态、复习和错题。
不负责自动邮件、日历或定时任务创建。

## 三维状态

学习进度：
未开始 / 进行中 / 用户自述完成 /
已完成且已验证 / 待复习 / 暂停

实验验证：
已验证 / 待验证 / 失败 / 不适用

知识掌握：
未评估 / 初步理解 /
能独立解释 / 能独立应用

三者不得混为一个状态。

## 完成判定
用户说“完成了”：
记录用户自述完成。

用户提供真实输出：
只验证该输出能够证明的目标。

用户确认文件已保存：
记录保存确认，不假定文件内容已检查。

没有反馈：
记录未收到反馈，不推断完成。

## 记录标识
学习：STUDY-YYYYMMDD-NN
错题：ERR-YYYYMMDD-NN
周报：WEEK-YYYY-Www

编号在同一日期或周期内必须唯一。
未知时使用待分配标识，不虚构编号。

## 每日学习
建议30–45分钟：
理论、操作、验证、总结。

## 错题管理
记录题目、来源、答案、错误类型、
解析、复习安排和再次作答结果。

建议复习间隔为1、3、7、14天，
根据实际掌握情况调整。

## 数据保存
模板来自assets/。
实际记录必须写入用户批准的目录。

写入前检查同名文件和已有内容，
优先追加或合并，不覆盖历史记录。

## 交付
学习进度草稿、错题草稿、
每周复盘和下一阶段学习建议。
