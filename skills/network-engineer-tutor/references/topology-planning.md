# 网络拓扑与IP规划

## 职责
负责网络结构设计、子网划分、地址分配、
冲突检查和验证计划。

实际配置操作交给vmware-labs.md。

## 输入信息
- 设备与虚拟机数量
- 操作系统
- VMware网络模式
- 主机数量和子网数量
- DNS、DHCP和网关需求
- 是否需要互联网
- 现有网络限制

## 规划流程
1. 确定通信需求
2. 划分广播域和子网
3. 计算子网容量
4. 规划网关与服务器地址
5. 规划DHCP地址池
6. 检查地址冲突
7. 绘制拓扑
8. 给出验证方法

## IPv4计算
普通子网主机数：
2^(32-prefix)-2

/31和/32按其实际用途单独处理。
检查网络地址、广播地址和地址重叠。

## 示例
以下仅为示例，不代表当前用户配置。

Server2022：192.168.168.10/24
Ubuntu：192.168.168.20/24
子网：192.168.168.0/24

同网段通信不一定需要默认网关。
