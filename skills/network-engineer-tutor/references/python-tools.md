# Python网络工具通用规范

## 职责
定义Python网络代码的通用开发、安全和测试规范。
具体项目任务由python-projects.md负责。

## 开发前检查
- Python版本
- 操作系统
- 项目路径
- 虚拟环境
- 依赖清单
- 现有未提交修改
- 网络测试授权范围

## 推荐标准库
socket：TCP/UDP通信
ipaddress：IP地址处理
argparse：命令行参数
logging：日志
subprocess：系统命令
json、csv：结构化数据
unittest：测试

## 代码规范
- 输入校验
- 超时设置
- 异常处理
- 连接与文件资源释放
- 明确的返回值
- 避免硬编码凭据
- 最小权限
- 可重复测试

subprocess优先使用参数列表，
避免不可信输入通过shell执行。

## 依赖管理
优先标准库。
引入第三方包时说明用途、版本和兼容性。
未经授权不安装依赖、不修改全局Python、
不覆盖现有虚拟环境。

## 测试要求
测试正常输入、错误输入、边界值、
网络不可达和超时情况。

优先使用模拟服务、回环地址
或明确授权的隔离实验环境。

## 结果记录
区分：
代码已生成
测试未执行
测试失败
测试通过

未运行测试不得声称通过。

## 项目保护
修改前检查现有文件和git状态。
未经批准不覆盖README、依赖清单或源代码。
