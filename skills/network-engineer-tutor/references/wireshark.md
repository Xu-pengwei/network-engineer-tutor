# Wireshark抓包与协议分析

## 职责
负责抓包准备、过滤器、协议字段分析和证据整理。

## 抓包前
确认：
- 操作系统与Wireshark版本
- 网卡及其地址
- 抓包权限与驱动
- 目标和授权范围
- 测试流量
- 数据敏感性

不得假定Npcap或Linux抓包权限已配置。

## 工作流程
1. 确认网卡
2. 明确授权测试范围
3. 开始抓包
4. 发起测试流量
5. 停止抓包
6. 应用显示过滤器
7. 找到请求与响应
8. 分析关键字段
9. 保存脱敏后的分析结果

实际抓包和主动测试必须符合SKILL.md授权规则。

## 显示过滤器
icmp
dns
tcp
udp
arp
ip.addr == 192.0.2.10
tcp.port == 443

192.0.2.10是文档示例地址。
不要将显示过滤器误称为捕获过滤器。

## ICMP分析
检查：
源和目的地址
Type、Code
Identifier、Sequence Number
请求和响应的对应关系
实际测得的往返时间

Echo Request为Type 8，
Echo Reply为Type 0。

## DNS分析
检查：
查询名称和类型
事务ID
响应码
Answer区域
TTL
查询与响应的对应关系

注意DNS缓存、DoH、DoT等情况。

## TCP分析
检查：
SYN、ACK、FIN、RST
序列号和确认号
窗口、重传和超时

不凭单个异常报文直接断定根因。

## 隐私要求
PCAP可能包含：
凭据、会话信息、内部地址、
DNS查询、设备标识和私人数据。

默认只整理必要字段。
未经批准不上传原始PCAP至公开仓库。

## 证据
记录抓包网卡、过滤器、测试目标、
报文编号、时间和关键字段。

没有真实报文时标记待验证。
